# Chico Coins

Primeira versão do aplicativo de controle financeiro pessoal.

## Como testar
Abra `index.html` em um navegador moderno. Os lançamentos ficam no armazenamento local desse navegador.

## Comandos reconhecidos
- `gastei 30 no mercado`
- `recebi 200`
- `mostrar meu saldo`
- `mostrar relatório do mês`
- `mostrar minhas dívidas`
- `mostrar histórico`

## Limitações importantes
Esta versão inicial não usa uma IA externa: reconhece comandos simples. Os dados ficam apenas no navegador atual, sem sincronização ou cópia de segurança. Não inclua dados sensíveis enquanto estiver testando. A conexão com uma IA real e a publicação online serão configuradas separadamente.
